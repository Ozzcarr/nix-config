# nix-config

NixOS configuration for my machines. Hyprland on Wayland, themed Catppuccin
Mocha, user config via home-manager.

## Hosts

| Host      | GPU    | Notes                                                    |
| --------- | ------ | -------------------------------------------------------- |
| `laptop`  | Intel  | Caps Lock as Esc/Ctrl, suspends on lid close             |
| `desktop` | NVIDIA | Dual monitor with pinned workspaces, never auto-sleeps   |

## Rebuilding

The shell aliases in `modules/home/zsh.nix` cover the common cases:

| Alias | Does                                              |
| ----- | ------------------------------------------------- |
| `fr`  | Rebuild and switch the system                     |
| `fu`  | Same, but update flake inputs first               |
| `hr`  | Rebuild just the home config (no system switch)   |
| `ncg` | Garbage-collect old generations                   |

Or directly:

```bash
sudo nixos-rebuild switch --flake ~/nix-config#laptop
```

Build without switching, to check a change compiles:

```bash
nixos-rebuild build --flake ~/nix-config#laptop
```

Build every host and home configuration at once:

```bash
nix flake check
```

## Layout

```
flake.nix              entry point; lists hosts, builds vars, wires inputs
hosts/
  common.nix           settings shared by all hosts
  <host>/
    default.nix        imports, GPU driver, host-specific services
    variables.nix      only what this host changes from common.nix
    hardware.nix       generated by nixos-generate-config
    packages.nix       packages only this host wants
modules/
  core/                system config (NixOS modules)
  drivers/             opt-in GPU drivers
  home/                user config (home-manager modules)
```

Every module receives `vars` (`hosts/common.nix` overridden by
`hosts/<host>/variables.nix`) plus `host` and `username` through `specialArgs`.

## Adding a host

1. `mkdir hosts/<name>`
2. `nixos-generate-config --show-hardware-config > hosts/<name>/hardware.nix`
3. Write `default.nix` (copy an existing one; set the right `drivers.*.enable`),
   `variables.nix` (only the differences from `hosts/common.nix`), and
   `packages.nix`.
4. Add `"<name>"` to the `hosts` list in `flake.nix`.

## Dotfiles

Config for tools that should also work off NixOS lives in the
[dotfiles](https://github.com/ozzcarr/dotfiles) repo, mapped into `~/.config` by
`modules/home/dotfiles.nix`. Add a program by putting its directory in that repo
and its name in the module's `managed` list.

## Fresh install

From the NixOS installer, with the disk already partitioned and mounted:

```bash
nix-shell -p git
git clone https://github.com/ozzcarr/nix-config ~/nix-config
```

Generate the hardware config for the new machine, add it as a host per the
steps above, then:

```bash
sudo nixos-install --flake ~/nix-config#<name>
```
